# RAVENO

A responsive interior design website built with React, JavaScript, and CSS for RAVENO, a premium interior design and bespoke furniture brand.

## Preview
![RAVENO website preview](screenshots/raveno-homepage.png)
![RAVENO website preview](screenshots/raveno-homepage1.png)

## Features
- Responsive design for desktop and mobile
- Reusable collection components
- Interactive image slider
- Image lightbox with navigation
- Keyboard interaction with Escape key

## Technologies
- React
- JavaScript
- HTML
- CSS
- Vite
- Git & GitHub

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/maryamhessampour-art/raveno-frontend.git
```

### 2. Install dependencies

```bash
cd raveno-frontend
npm install
```

### 3. Start the development server

```bash
npm run dev
```
